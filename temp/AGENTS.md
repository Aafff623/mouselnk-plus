# Temp Rules

- 临时项目材料放进 `temp/` 下合适的子目录。
- 来源重要时，原始用户输入原样保存在 `input/`，不要改写。
- 调研放 `research/`，报告放 `reports/`，跨会话交接放 `handoff/`。
- 实验脚本与临时 HTML/CSS/JS 放 `scripts/` 或 `preview/`。
- 本地凭据与配置备份只放 `secrets/`；绝不回显其取值，也不复制进被跟踪的文件。
- 报告和交接件在用户明确提升之前，不算耐久项目文档。
- 不要自动删除或清理 `temp/` 材料。破坏性清理前先问。

## 本项目的额外约定

- `input/mouseinc-author-spec.md` 是作者回复的技术路线原文，是本工程的**需求基准**。owner 补发后原样落盘，不要改写、摘要或重排；需要提炼时另建文件。
- `research/` 里的调研报告里的结论若与 `CONTEXT.md` 冲突，以 `CONTEXT.md` 为准（本机实测优先于网络资料）。发现冲突时同时更新两处并说明。
