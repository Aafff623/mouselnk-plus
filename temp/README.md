# Temporary Project Workspace

`temp/` 是本地工作区，用于存放帮助调查或开发本项目、但不属于提交产物树的材料。

按需使用各子目录：原始输入、调研、实验脚本、预览、报告、交接件、日志、缓存与本地凭据。需要时才创建子目录；不要把临时文件散落到无关的磁盘或项目位置。

载荷被 Git 忽略。`README.md` 与 `AGENTS.md` 是说明这条边界的两个入口，必须保留。

## 当前已有的子目录

| 子目录 | 内容 |
|---|---|
| `input/` | 作者技术路线原文等原始需求材料，**保持原样不改写** |
| `notes/` | 不进公开仓库的本机事实（如参考程序的精确安装路径） |
| `research/` | MouseInc / Aitiy 的上游调研报告 |
| `secrets/` | 本机取到的凭据（被 Git 忽略） |
| `scripts/` | 一次性脚本与验证工具（如 `vscheck/verify-toolchain.bat` 工具链验收） |
| `logs/` | 工具链安装等长任务的日志 |
| `reports/` | 需要产出的分析报告 |
| `handoff/` | 跨会话交接件 |
